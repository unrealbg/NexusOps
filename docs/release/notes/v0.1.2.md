# NexusOps 0.1.2

This patch release corrects the application version shown in the NexusOps sidebar. The displayed version now uses the complete release-verified SemVer, so this release shows `v0.1.2` instead of the abbreviated `v0.1`.

- Windows x86_64 supports check, download, verification and explicit installation.
- Linux x86_64 and macOS aarch64 support check, download and verification; in-app installation is unavailable.
- Windows ARM64 is not included in this release artifact set.
- Automatic checking, download, installation, restart and relaunch remain disabled.

The Windows installer is authenticated by the NexusOps updater signature but is not Windows Authenticode-signed. Windows may display an unknown publisher.
